# calculadora-java-swing
Uma calculadora funcional e interativa desenvolvida inteiramente em Java utilizando a biblioteca Swing.

Funcionalidades
* Operações matemáticas básicas (Soma, Subtração, Multiplicação, Divisão).
* Memória de cálculo contínuo (estilo calculadora de mesa).
* Tratamento de erros (ex: bloqueio de divisão por zero).
* Botões de limpeza de memória (CE), apagar tudo (C) e deletar último dígito (del).

Tecnologias Utilizadas
  Linguagem: Java
  Interface Gráfica: Java Swing
  IDE: Apache NetBeans
